# Microduck Color Studio

**简体中文** · [English](README.en.md)

Microduck 3D 配色工作室。基于真实的 Microduck 装配模型，逐件调整颜色、材质与灯光，把脑海中的配色变成可以旋转查看的效果。

**[在线体验](https://lathamz.github.io/microduck-color-studio/)**

![Microduck 配色工作室：36 秒功能演示](docs/media/studio-demo.gif)

## 能做什么

- **逐件配色**：70 个独立装配实例，支持点击模型选择、按名称或 ID 搜索、同名零件批量调整。
- **立体查看**：旋转、缩放、标准视角、单件隔离、展开装配和隐藏标准硬件。
- **材质与灯光**：PLA、哑光 PLA、丝绸 PLA、PLA-CF、PETG、哑光 PETG、金属质感 PETG、碳纤 PETG、ABS、ASA、PC、尼龙 PA、碳纤尼龙、TPU 外观预设；摄影棚、日光、暖光各有独立灯位与背景，电影模式是纯黑场景只用布光。**打光方式**可叠加在任意场景上：蝴蝶光、伦勃朗光、分割光、轮廓光。另有可调强度、方向和光源角度，以及近似层纹。
- **模组切换**：右上角一键在**步行**与**轮滑**之间切换；没装上的那一套会摆到鸭子脚边的地上，大约隔开一个身位，两套零件都能选中、一起配色，而不是只能改鸭子身上正穿着的那部分。换上轮滑之后，靠脚掌落地的动作会从菜单里收起，只留下轮子能做的那几个。
- **动作演示**：动作按钮可以让鸭子动起来，默认循环播放「走路 → 摇头 → 走路 → 张嘴」，悬停按钮可以单选某一种动作：走路、坐下站起、踢一下、叼一口、翻身站起、摇头、歪头、张嘴。走路是摇摇晃晃的：鸭子腿短身宽，重心不可能夹在两脚之间，所以躯干会倒向承担体重的那只脚、并跟着往那一侧偏过去，髋部再反向开合把支撑脚留在原地（真实鸭子走路时拧膝盖就是这个动作），头部反向侧倾保持视线水平。每条腿都由逆运动学解算：脚掌路径先定，再解髋／膝／踝舵机角度，支撑脚始终贴地；坐下时臀部向脚掌下沉，腿部舵机按同样的量折叠；叼一口靠颈根、颈俯仰和下颚独立完成；翻身站起时身体绕着**当下真正接触地面的部位**翻转——先是脚后跟，然后是臀部，接触点会随之转移。零件展开时会自动停止。
- **保存方案**：颜色、材质、涂色与灯光统一保存，支持撤销、重做、JSON 导入导出、浏览器本地保存和 PNG 效果图。右上角 **方案** 菜单可以把当前配色存成多套方案，随时一键切回、重命名、覆盖或删除。
- **库存推荐**：记录已有耗材，比较“只用已有”“补充一色”和“丙烯点缀”方案，明确区分现有料、建议补料与后期涂色。点选一卷耗材即可与该零件**联动**，之后在素材库里改颜色或材质，模型上所有联动零件会一起更新。
- **打印模型导出**：上传自己的 3MF，按名称相似度自动关联配色（可信度 ≥ 80% 直接匹配，50–80% 选出最相近者并标注请核对），按颜色／材质或部件分盘，下载保留颜色的多盘 3MF 项目、逐件 STL 和 JSON 清单。
- **随机标语**：打开页面随机出现一句鸭子宣言，点击标题旁的按钮即可换一句。
- **Agent 接口**：稳定零件 ID、版本化 JSON Schema、命令行工具和显式浏览器 API，支持调色、改材质、打光和库存推荐。
- **可替换模型**：通用渲染、编辑状态与模型数据包分离，后续可以接入其他模型。

界面支持简体中文与英文，右上角 **地球图标 + 当前语言（中文 / English）** 可切换语言，保留已有配色和库存。用户填写的耗材名称不会被自动翻译。

## 从配色到分盘

1. **导入 / 导出**主按钮处理 JSON 配色配置；点击**导出右侧箭头 → 导出 3D 打印模型**进入打印流程。
2. 上传实际要打印的 **3MF**，例如 HD1910 版本。网页不会把 XL330 展示网格当作 HD1910 打印件，也不会替换当前配色视图。
3. 核对零件关联。名称按相似度自动匹配，忽略大小写、分隔符、文件后缀和序号前缀（`ankle_left_v2` 会匹配到 `ankle_left`）；可信度 50–80% 或多件同名时会标注**请核对**。**可信度低于 50% 的零件会标红色 `*`**，并在导出时保持源文件颜色；你可以手动关联，不改也能直接导出。取消勾选不需要打印的对象。
4. 选择 **P1S、H2D、A1 mini、X2D** 预设，或选择自定义并输入底板宽、深和可用高度，再设置边距与零件间距。机型只影响分盘尺寸与多盘位置对齐，不设置温度、速度或打印工艺。选择“相同材质与颜色同盘”或“部件、材质与颜色分盘”，点击**预览分盘**。
5. 下载 ZIP 打印包。在切片软件中打开**microduck-print-project.3mf** 多盘项目，颜色和排布保存在文件里；`stl/` 内另附逐件 STL，`print-plan.json` 记录对应关系、材质、颜色和位置。

STL 本身不保存颜色。导出的 3MF 是带颜色的模型排盘文件，**不是已切片的打印任务**：需在切片软件中设置打印机、耗材工艺、支撑与裙边。原文件的支撑涂色、切片参数和 G-code 不会随包导出。丙烯涂色记录为后处理，按底材颜色分盘。

仅在本地浏览器处理上传文件，不上传服务器、不随项目开源分发。保留源文件的打印旋转与比例，仅平移贴床和排盘，不自动修复或缩放。当前接受毫米单位、含三角网格的 3MF（包括 Bambu 的组件引用）；修改器／负体积需先在切片软件中处理。导入上限为 100 MB 压缩文件、300 MB 解压数据、300 万三角面和 500 个对象。

## 手机预览

手机自动加载约 30 万面的轻量模型，并降低像素密度、阴影和环境贴图开销；电脑使用约 80 万面的完整模型。手机端隐藏 JSON 导入导出及打印导出入口，保留查看、调色和材质控制。浏览器不支持 3D 或显存丢失时，会提示使用电脑打开。不同 iPhone / Safari 版本与内存条件仍可能影响加载。

多盘项目采用 **Bambu Studio / OrcaSlicer** 兼容格式；其他切片软件可能读取几何和颜色，但不识别多盘元数据。

## 本地运行

需要 Node.js 22 和 npm。

```sh
npm ci
npm run dev
```

打开终端中显示的本地地址。生产构建使用 `npm run build`，将 `dist/` 部署到任意静态网站服务即可。

项目无需后端、登录、API Key 或打印机连接。网站使用 Google Analytics 统计访问情况（衡量 ID：`G-FK57KHWFPV`）。配色、库存和上传的打印模型仍在浏览器本地处理，不作为自定义统计事件发送；导出 JSON 可以跨设备备份。自行部署时可在 `index.html` 中替换或移除 Google tag。

## 使用自己的耗材

打开右上角 **我的耗材**，填写实际拥有的耗材名称、颜色与材质。

| 推荐方式 | 处理逻辑                                               |
| -------- | ------------------------------------------------------ |
| 只用已有 | 优先使用库存内的颜色和合适材质，缺少必要材质时明确提示 |
| 补充一色 | 最多建议额外购买一卷配色料，缺少的必要材质另列         |
| 丙烯点缀 | 使用现有料打印，再为允许涂色的硬质外观件建议丙烯笔补色 |

右侧控制面板将已有耗材单独展示：点选一卷耗材即可与该零件联动，之后在「我的耗材」里改这卷料的颜色或材质，所有联动零件会一起更新（手动改色即解除联动，可随时重新点选）。库存列表会标出每卷料当前联动了多少个零件。推荐区的 **换一换** 可探索不同组合；库存有限时会如实提示。

推荐使用确定性的颜色距离匹配与配色模板，不把主观审美包装成精确评分。柔性件保留 TPU 要求，不能为了颜色而换成硬质料。涂层颜色单独记录，不会覆盖实际打印本色。

## 给 Agent

从 [AGENTS.md](AGENTS.md)、[接口文档](docs/agent-api.md) 和 [架构设计](docs/architecture.md) 开始。

```sh
npm run -s palette -- parts --role primary
npm run -s palette -- new --out my-look.json
npm run -s palette -- edit --in my-look.json --patch examples/warm-petg.patch.json --out warm-look.json
npm run -s palette -- validate --in warm-look.json
npm run -s palette -- recommend --inventory examples/inventory.json --mode paint --out suggestions.json
```

命令行和网页共用同一套校验与状态格式。结果输出为 JSON；错误写入标准错误并返回退出码 1。`--out` 不覆盖已有文件。浏览器在准备完成后提供 `window.colorStudio`。

## 架构与开发

- `src/domain.ts`：独立于模型和界面的状态、校验与历史记录。
- `src/viewer.ts`：通用 Three.js 渲染、拾取、材质、灯光与相机。
- `src/recommend.ts`：库存校验和配色推荐。
- `src/models/`：当前模型的接入配置与配色模板。
- `public/models/`：GLB 几何与具名零件清单。
- `src/api.ts`、`scripts/palette.ts`：人机共用的公开接口。

接入其他模型请阅读 [模型数据包规范](docs/model-pack.md)。常规运行无需 Python，也不依赖开发者的其他仓库。

```sh
npm test
npm run build
npm run format:check
```

CI 模板位于 `.github/ci.example.yml`。使用具备工作流写入权限的 GitHub 凭证，将其移至 `.github/workflows/ci.yml` 即可启用。

`main` 是默认源码分支；`gh-pages` 只保存构建生成的在线网页。

## 模型范围与效果边界

这是外观配置工具，不是切片软件或装配尺寸校验工具。当前模型来自原版 **XL330 仿真装配**，保留约 79.7 万个原始三角面；它不是精确的 HD1910 装配模型。右上角可以在**步行**与**轮滑**之间切换：轮滑模组用的是官方仿真里那套替换件（轮滑脚踝、刀架、四个轮子），摆放位置逐件取自官方 Mujoco 模型，轮滑脚踝比标准脚踝高 10 mm，所以换上后整只鸭子站得更高。

70 个可视实例中，36 个标记为打印件、34 个为标准硬件；这一数量**不是打印 BOM**。网页不会修改 `.3mf`、STL、CAD 仓库或打印机。

材质效果为近似模拟，未按具体耗材品牌实测。PETG 以不透明材质展示，TPU 不模拟形变；0.4 mm 层纹按装配竖直方向生成，不代表各零件真实打印朝向。丙烯涂色需先用试片检查附着效果。屏幕颜色也不等同于实物色。
